# Samsung Health Data SDK

Samsung distributes the Samsung Health Data SDK as a licensed Android AAR. Download the current SDK from Samsung's developer site, review and accept its license yourself, then copy the API AAR into this directory. The app Gradle file includes AAR files from this folder.

The AAR is intentionally excluded from Git by the local .gitignore. Do not commit Samsung's licensed SDK binary.

Official setup guide: https://developer.samsung.com/health/data/guide/hello-sdk/app-module.html
